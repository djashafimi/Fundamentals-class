2) Variable
=============

variable is a container to store data.

eg: x=10;
    name="Anu";

Rules to declare variable
===========================

* variable can be declared with the combination of alphabets, numbers and "_"

* Except "_" no other symbols are used.

* A number alone cannot be used as variable

* A variable starting with number is also not allowed

* A variable is case sensitive, which means "a" and "A" are different
Data type
===========

The type of data assigned to a variable is called data type.

num=10	//integer

price=20.50 //float

name="Anu" //string

valid= true/ false //boolean



Type casting
================

Changing the datatype of a variable into another datatype.
Number()	// string to number
parseInt()	// string to integer
parseFloat()	// string to decimal number
